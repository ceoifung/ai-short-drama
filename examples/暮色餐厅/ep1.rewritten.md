# 三、正文（小说化）

"啪——！"

瓷碗砸在八仙桌上的脆响，比人声先炸开。

慢镜里，排骨汤溅起一片油亮的水花。紧跟着，一声怒吼劈头盖脸砸下来——

"十九块八？！一顿饭，吃掉我儿子半天的汗水钱！"

黑屏半秒，白字砸出来：**一碗排骨汤，掀翻了一个家。**

角标浮出：三分钟前。

城中村自建楼一层的堂屋里，老排风扇嗡嗡转着，十五瓦的灯泡把四菜一汤照得发亮。

苏念慈把最后一碗冬瓜排骨汤端上桌，手在围裙上擦了擦："吃饭了。"

话音未落，婆婆王秀琴的筷子已经伸进汤碗，筷子尖挑起一块排骨，眯着眼端详了半天，忽然把筷子往桌上一拍——

"这排骨，多少钱一斤买的？"

"妈，十九块八。"苏念慈一愣，"我特意挑的肋排中段，小舟长身体——"

"十九块八？！"

就是这一嗓子。王秀琴的声音陡然拔高，震得灯泡都在晃："我儿子在外面跑工地，中午就啃俩馒头！你倒好，一顿饭吃掉他半天的工钱！"

苏念慈的手指在桌沿收紧，又慢慢松开。她瞥了一眼儿子的房门，压低声音："妈，小舟这次月考进了年级前五十，我就想给他补补。"

"补补？"王秀琴冷笑一声，扭头朝里屋喊，"老周！你出来看看你媳妇儿干的好事！一顿汤，喝掉你半条命！"

周建军趿着拖鞋出来，手里还捏着半个没啃完的馒头。他扫一眼桌上的四个菜一锅汤，眉头拧成疙瘩："又是排骨？上礼拜不是刚吃过？"

"上礼拜是我妈忌日，那天吃的素。"

苏念慈的声音很轻，轻得像怕碰碎什么。

周建军没听出这话里的东西，摆摆手："行了行了，吃饭。妈，您消消气。"

"消什么气？"王秀琴不依不饶，"这个家，谁挣钱谁说了算！"

她把那碗排骨汤往自己面前一拖："来，小舟，坐外婆边上，外婆喂你。"

房门开了。周小舟背着书包站在门口，看见的就是这么一幅画面：外婆端着他最喜欢的那碗汤，妈妈站在桌角，围裙都没来得及解，眼圈是红的。

"妈——"他喊了一声，伸手要去拉妈妈。

王秀琴把汤碗往桌上一顿！

汤汁溅出来，泼在苏念慈搭在桌沿的手背上。

苏念慈猛地缩回手，胳膊肘碰翻了旁边的醋瓶。醋淌了半张桌子，顺着桌缝往下滴。

滴答。滴答。

堂屋里静得只剩这个声音。周建军转身去找抹布，王秀琴别过脸去。没有一个人说对不起。

苏念慈攥着自己的手腕，忽然笑了一下——笑得比哭还难看。

她解下围裙，叠得整整齐齐，搭在椅背上。然后弯下腰，从碗柜最底层，摸出一个豁了口的粗瓷碗。

那是她妈留下的，唯一一件东西。

她用拇指摩挲着碗沿的豁口，轻得像自言自语："妈。"

黑屏。字幕三行：

**被烫了手，还得赔笑道歉。**

**如果是你，这碗汤你还端不端？**

**右边一排，点亮，评论区给我评评理。**

# 五、改写说明（4条）

1. **黄金三秒如何设计**：镜头0爆点前置——瓷碗砸桌炸响+重低音，配"十九块八？！"怒吼大特写与升格汤溅，3秒内完成耳光级冲击；黑屏字卡"一碗排骨汤，掀翻了一个家"立住悬念，角标"三分钟前"回正叙，镜头2同一句怒吼复现，形成爆点回环，钩子闭环不掉观众。
2. **冲突如何升级**：盘问价格（刻薄）→ 当众算账羞辱（暴怒）→ 喊儿子助阵+丈夫和稀泥（拉偏架）→ "谁挣钱谁说了算"抢汤碗（宣示主权）→ 顿碗溅汤烫手+无人道歉（顶点心寒）→ 豁口碗+轻唤"妈"（隐忍转向悬念）。情绪四层递进：刻薄→暴怒→委屈→心寒，每15秒一个新冲突点。
3. **互动钩子如何埋**：三个"引战点"全程保留放大——嫌贵（十九块八）、翻旧账（啃馒头）、抢孙子（"外婆喂你"），天然让观众分成"婆婆有理/儿媳委屈"两队；结尾黑屏字幕直接站队式提问"如果是你，这碗汤你还端不端？右边一排，点亮，评论区评理"；"我妈忌日"伏笔+豁口碗定格双重悬念引导追更第2集。
4. **合规如何处理**："耳光"冲击力以怒吼+器物砸桌音效实现，全片无肢体暴力画面；烫手只拍缩手、攥腕与表情反应，镜头说明中明确"不给伤处特写"；台词无脏话，初稿"败家玩意儿"改为"干的好事！一顿汤，喝掉你半条命"，保留攻击性但无侮辱性字眼；冲突全部通过台词、表情、器物动作体现，无公序良俗风险。
